# SingMotion AI analytics rollout — November 26, 2026

## Scope and status
Existing Payload Customer Insights remain the authoritative source for actual customers, credit purchases, verified videos and refunds. Google Search Console is already verified for https://www.singmotion.ai/. No new database, advertising pixel or payment tracking is introduced. The website's English UI is retained.

The initial GA4 integration is for exact public marketing pages only. Private account, payment, admin, studio and project pages are excluded; query-bearing and fragment-bearing URLs are excluded entirely (including the home private carousel ?card parameter); referrer paths are not submitted as page-view parameters. Campaign IDs/UTM attribution, ad cookies and verified signup/purchase conversions are **not yet enabled**. Google Ads/Meta/TikTok integrations require separately approved consent purposes and implementation. Current Google tracking must remain disabled until the acceptance checklist below is complete.

## Configuration
- Staging: GA4_ENABLED=false and GA4_CONSENT_PREVIEW=true for UI-only review; the preview stores a distinct preference and never loads Google. Operator decision: Staging is private and will remain preview-only. No separate GA4 property or real measurement ID is required; never configure the Production ID on Staging.
- Production: GA4_ENABLED=false and GA4_CONSENT_PREVIEW=true until the live release gate. The banner can be reviewed without Google requests and explains that the preview choice does not carry over to live consent. When tracking is approved, use GA4_ENABLED=true. Staging cannot activate a Google tag even if accidentally configured.
- GA4_MEASUREMENT_ID: real G-... web stream ID, separately set per environment only after verification. Never use an example ID. The browser only receives the public measurement ID if explicitly enabled in Production.
- Consent preference stores version, decision and timestamp locally for 180 days; an ID-specific key prevents a preview decision from granting consent to a live property. No additional unique visitor identifier is generated by our app.
- Analytics consent defaults denied; advertising storage, user data and personalization remain denied. No Google script until affirmative consent and an allowlisted route. Withdrawal disables the tag, removes recognized GA cookies and reloads the current page. GA cookie lifetime is configured to 180 days without automatic renewal; verify effective settings in the real browser. A link from a tracked page into a private or query-bearing view uses a fresh document. Client navigation and cross-tab revocation also disable the tag and reload as needed; these are defensive controls, not proof of complete third-party script isolation.

If the live network audit fails, disable GA4 immediately; do not open the site for public tracking until the audit passes. Do not change public-access or crawler gates as part of this change.

## Future marketing and buyer readiness
Use the existing verified Search Console for organic search visibility; no HTML verification change is needed. Preserve aggregate monthly analytics exports and access ownership. GA4 visitor totals reflect consenting visitors, not every visit.
For paid campaigns, implement separately consented advertising features only after review, with explicit approved campaign metadata (no arbitrary URL values or personal data). For GA4 key events, add signup only after confirmed account creation and purchase only after verified settlement, deduplicating by a non-personal transaction key; never count a checkout click as revenue, never send emails, account IDs, project IDs or payment credentials. Existing credit ledger and refund figures are the authoritative business totals; don't invent recurring revenue or subscriptions. No new conversion emission, account linkage, Ads account or budget is configured by this change.
For handover, document property roles, data retention, consent and privacy obligations; transfer project-owned assets with appropriate legal basis, not raw customer information by default.

## Browser regression
Run `node --experimental-strip-types tests/analytics-consent.browser.ts` after building the application and installing Chromium through Playwright. The test uses an isolated local server, synthetic measurement ID, and intercepted mock Google tag; no requests to Google or real customer records are permitted. It checks no tag before choice, equal accept/reject controls, rejection persistence, one explicit page view after acceptance, no tag on private query URLs, and cross-tab revocation. It is not a substitute for the controlled real-tag network audit on Production after legal review; no Staging property is necessary.
